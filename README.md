# Receipts App

This README file is generated by AI.

## Overview
This project extracts structured fields (date, amount, vendor, category) from receipt images.

## Setup
1. Create and activate a virtual environment (optional but recommended).
2. Install dependencies:

```bash
python3 -m pip install -r app/requirements.txt
```

3. Set your OpenAI API key:

```bash
export OPENAI_API_KEY="your_api_key_here"
```

## Run
From the repository root:

```bash
python3 src/receipts_app/main.py app/receipts --print
```

- The first argument is a directory path containing receipt images.
- Use `--print` to output JSON to stdout.

## Notes
- The default sample images are in `app/receipts`.
- If you move or rename the receipts folder, pass the new path to the command above.
